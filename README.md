# CCレモンガイド

CCレモンゲームの気力を記録し、事前計算した均衡戦略から自分の手を抽選するガイドです。

[ガイドを開く](https://merogame.github.io/cc-lemon-guide/)

画面に表示するのは相手と自分の気力、自分の手、相手の手を入力する4ボタンだけです。一画面で使える、約7KBの単体HTMLです。

## 使い方

1. `CCレモンガイド.html` をブラウザで開きます。GitHub Pagesでは `index.html` が同じゲームを表示します。
2. 中央に表示された手を出し、相手が出した手のボタンを押します。
3. 気力と次の手が更新されます。
4. 決着後は中央の「勝ち」「負け」をタップすると、気力0から再開します。

相手の気力で使えない手は入力できません。再読み込みすると対戦は初期状態に戻ります。

## ルール

二人が同時に手を出します。気力の初期値と最低値は0です。

| 手 | 気力の変化 | 効果 |
|---|---:|---|
| 溜め | ＋1 | 気力を増やす |
| 防御 | 0 | 攻撃を防ぐ |
| 攻撃 | −1 | 相手が溜めなら勝利 |
| 必殺 | −5 | 相手が必殺以外なら勝利 |

気力が不足する手は使えません。攻撃同士、必殺同士など、勝敗が決まらない組み合わせでは気力を更新して続行します。必殺は防御でも防げません。

## 手の選び方

優先順位は次の通りです。

1. 自分の気力が5以上なら、必敗の局面でも必殺を選ぶ。
2. 必殺を使えず、相手が最善を尽くすと必敗になる局面では溜めを選ぶ。
3. それ以外は保存した均衡戦略から抽選する。

同じ手番のおすすめは固定され、相手の手を入力した後に次の抽選を行います。

## 均衡と精度

勝ちを＋1、負けを−1、無限に続く対戦を引き分け0として数値計算しています。相手が抽選確率を知り、対局全体で最善の対処をする場合を基準にします。

必殺を使えるときは、他の手を選ぶより不利になりません。両者が必殺を出せば気力が5ずつ減り、片方だけが出せば決着します。この性質で、自分と相手の気力0〜4の25局面に整理できます。気力上限、手数上限、割引率は設けていません。

確率は小数点以下7桁で保存し、攻撃の確率は溜め・防御の残りから求めます。各局面の確率を0〜255の整数に丸める方式は採用していません。

保存表に対する最適な対処を計算した検証結果は次の通りです。

- 初期状態の理論勝率：50%。
- 保存表を使った初期状態の最悪勝率：約49.999984%。
- 全25局面での、理論値からの最大勝率低下：約0.0000204ポイント。

これらは浮動小数点の数値計算による検証結果です。

## 構成

| ファイル | 用途 |
|---|---|
| `index.html` | GitHub Pagesの入口 |
| `CCレモンガイド.html` | 保存して使う単体HTML。`index.html` と同一内容 |
| `.nojekyll` | GitHub Pagesで静的ファイルをそのまま配信する設定 |
| `tools/solve-equilibrium.mjs` | 均衡表の事前計算 |
| `tools/verify-accuracy.mjs` | 保存表に対する最適な対処の計算と精度検証 |
| `tools/equilibrium.json` | 計算した均衡と確率 |
| `tools/accuracy.json` | 保存表の精度検証結果 |

外部ライブラリ、外部フォント、画像ファイル、サーバー処理は不要です。利用中に均衡を再計算したり、入力した手や気力を送信したりする処理はありません。ブラウザが対応している場合は、相手の手を記録するWebMCPツールも同じページ内で利用できます。

ページ内のピンチ、ダブルタップ、ホイール、拡大ショートカットは抑止しています。ブラウザ自身の設定やアクセシビリティ機能による拡大は、ページから完全には禁止できません。

## 再計算

Node.jsがあれば、追加パッケージなしで実行できます。

```sh
node tools/solve-equilibrium.mjs
node tools/verify-accuracy.mjs
```

前者は `tools/equilibrium.json`、後者は `tools/accuracy.json` を更新します。HTMLの確率表は自動更新されません。表や動作を変更するときは、2つのHTMLを同じ内容に更新してください。

## GitHub Pagesで公開

リポジトリの **Settings → Pages** で、Sourceを **Deploy from a branch**、Branchを **main**、フォルダーを **/(root)** にして保存します。

公開手順の詳細は [GitHub公式ドキュメント](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) を参照してください。
