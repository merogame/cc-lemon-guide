# じゃんけんガイド

[ガイドを開く](https://merogame.github.io/cc-lemon-guide/janken/)

中央に自分の推奨手、画面下に相手の手を入力する「グー・チョキ・パー」の3ボタンだけを表示します。一画面で使える単体HTMLです。

## 使い方

1. 中央に表示された手を出します。
2. 相手が出した手のボタンを押します。
3. 次の推奨手が抽選されます。あいこでも同じ操作です。

同じ手番の推奨手は固定されます。次も同じ手が表示されることがあります。

## 抽選と精度

通常のじゃんけんの均衡戦略は、グー・チョキ・パーをそれぞれ1/3で選ぶことです。相手の手や履歴で確率は変えません。各回を独立に抽選します。

ブラウザの `crypto.getRandomValues` で32ビット整数を生成し、最大値だけは引き直してから3で割った余りを使います。各手に対応する整数の個数が等しいため、整数への丸めによる確率の偏りはありません。均衡表の保存や重い計算は不要です。

相手が推奨手を見ることなく同時に出す場合、勝ち・負け・あいこはそれぞれ1/3です。決着した回だけを数える勝率は50%です。

## ファイルと動作

- `index.html`：公開ページ。ファイルを保存して直接ブラウザで開くこともできます。
- `README.md`：この説明。

外部ライブラリ、外部フォント、画像、サーバー処理、追加通信は使いません。相手の手や対戦履歴を保存・送信する処理もありません。

ページ内のピンチ、ダブルタップ、ホイール、拡大ショートカットは抑止しています。ブラウザ自身の設定やアクセシビリティ機能による拡大は、ページから完全には禁止できません。
